## 539-Grad-Project- eBird Data Analysis ##
## Chloe Hays - Author ##
This project analyzes field observations of bird sightings across four sites in Rhode Island, all data was 
pulled from the software eBird created by the Cornell Lab of Ornithology. This sightings are RECENT and 
have not historically been collected. It is only sightings of one bird, the important information here is 
the species that are being observed. I chose these four sights because they were taken at locations I 
will be surveying over the summer, with the exception of a private residence that I was interested in 
analyzing to see how species sighted compared to other public sights. 

## Purpose of Analysis ##
What species are being spotted at certain locations, i.e. are the same birds in backyards being
sighted at wildlife refuges, more urban environments, etc.? 
## Data ##
Source: eBird, Cornell Lab of Ornithology
Date of Observations: Recent

## Methodology Used ##
-Data coding using R studio
-Data visualization using ggplot2
-Data summarizing using dplyr
-Pushed data to github repository using R terminal
-Obtained data throuh rebird package
